# أكاديمية هيم المحلة - الموقع الرسمي

## 🌐 معلومات الموقع

هذا موقع أكاديمية هيم المحلة للعلوم الإدارية، تم تصميمه ليكون مشابهاً لمواقع الأكاديميات الكبرى مع التركيز على هوية الأكاديمية الخاصة.

## 📁 هيكل الملفات

```
him/
├── index.html          # الصفحة الرئيسية
├── css/
│   └── style.css      # ملف التنسيقات
├── js/
│   └── script.js      # ملف الجافاسكريبت
└── images/            # مجلد الصور (يحتاج لصورك)
```

## 🎨 التخصيص المطلوب

### 1. الصور

ضع الصور التالية في مجلد `images/`:

- **logo.png** - شعار الأكاديمية (حجم مقترح: 200x200 بكسل)
- **business-systems.jpg** - صورة قسم نظم معلومات الأعمال
- **accounting.jpg** - صورة قسم المحاسبة والمراجعة
- **business-admin.jpg** - صورة قسم إدارة الأعمال
- **academy-building.jpg** - صورة مبنى الأكاديمية
- **news1.jpg, news2.jpg, news3.jpg** - صور للأخبار

### 2. معلومات الاتصال

في ملف `index.html`، عدّل البيانات التالية:

```html
<!-- الهاتف -->
<span><i class="fas fa-phone"></i> 01012345678</span>

<!-- البريد الإلكتروني -->
<span><i class="fas fa-envelope"></i> info@him-mahalla.edu.eg</span>

<!-- العنوان -->
<p>المحلة الكبرى، الغربية، مصر</p>
```

### 3. الألوان

يمكنك تغيير ألوان الموقع من ملف `css/style.css`:

```css
:root {
    --primary-color: #1e3c72;      /* اللون الأساسي */
    --secondary-color: #2a5298;    /* اللون الثانوي */
    --accent-color: #f39c12;       /* لون التركيز */
}
```

### 4. النصوص

عدّل النصوص في `index.html` حسب محتوى الأكاديمية الفعلي:

- كلمة رئيس الأكاديمية
- وصف الأقسام
- الأخبار والفعاليات

## 🚀 كيفية التشغيل

1. افتح المجلد في المتصفح:
   ```
   انقر نقراً مزدوجاً على ملف index.html
   ```

2. أو استخدم Live Server في VS Code:
   - قم بتثبيت امتداد Live Server
   - انقر بزر الماوس الأيمن على index.html
   - اختر "Open with Live Server"
